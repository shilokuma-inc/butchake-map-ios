# アプリアイコンの候補

「ぶっちゃけmap」のアプリアイコンの候補 30 案（Issue #58）。採用案は PR で選び、決まったらアプリへの適用（`.icon`・iOS 17〜25 用の PNG）は別の PR で行う。

- 元データは SVG（`candidates/NN.svg`）が正本。PNG は選ぶための見本で、コミットせず PR に添付する
- 1024×1024 の全面に背景を敷き、角丸は描かない（iOS がマスクをかけるため。App Store は透過付きのアイコンを受け付けない）
- 画像生成 AI や外部の素材は使わず、図形だけで組んでいる（座標と色は `scripts/make_candidates.py`）
- 文字は OFL の書体のアウトラインをパスにして埋め込んでいる（`glyphs.json`）。端末やフォントの有無で見た目が変わらない

## 文字に使った書体

どれも Google Fonts の SIL Open Font License 1.1 の書体。書体のファイルはリポジトリに入れず、使う文字のアウトラインだけを `glyphs.json` に持つ。

| キー | 書体 | 使った案 |
| --- | --- | --- |
| `dela` | Dela Gothic One | 01・02・07・09・10・26 |
| `mochiy` | Mochiy Pop One | 04・05・08・22・28・29 |
| `antique` | Zen Antique | 12・16・18 |
| `yuji` | Yuji Syuku | 13 |

## 作り直し方

```bash
# 候補の SVG を作り直し、PNG（build/app-icon/）に書き出す
design/app-icon/scripts/export_png.sh

# 使う文字を増やしたときだけ: 書体を取得して glyphs.json を作り直す（xcrun swift を使う）
design/app-icon/scripts/extract_glyphs.sh
```

`export_png.sh` は `make_candidates.py` で SVG を書き出してから、macOS 標準の QuickLook（`qlmanage`）で PNG にする。
書き出すもの:

- `build/app-icon/candidates/NN.png`: 候補（1024×1024）
- `build/app-icon/group-a.png`・`group-b.png`・`group-c.png`: 系統ごとの 10 案（ホーム画面の角丸をかけたもの）
- `build/app-icon/home.png`: 30 案をホーム画面の大きさ（60pt を 3 倍の 180px）で並べたもの
