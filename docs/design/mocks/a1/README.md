# A-1「王道ポップ」

方向性 A（ポップ＆ツッコミ）の 1 案目。Discussion #45 の A の説明をそのまま形にした案です。

## コンセプト

オレンジとイエローに、黒の太い線（3pt）とずらした影。見出しは極太の丸ゴシック、バッジや見出しの札は少し傾けたステッカーにして、
「ぶっちゃけ」のツッコミ感とにぎやかさを出します。背景はうすいクリームに小さな水玉を敷き、白いカードを浮かせます。

## 「面白さ」の出し方

- ロゴ・バッジ・見出しの札を少し傾け、手で貼ったステッカーのように見せる（`バズり中！`・`みんな推し`・`毎週更新`・`アツい！` など、いいねの数や見出しに合わせた一言）
- ぶっちゃけコメントを吹き出しにして、地元民や旅人が話しかけてくる感じにする。ホームの上にも「今日はどこの本音、のぞいちゃう？」の吹き出しを置く
- 順位は黒地に黄色の数字のリボン（`1位`）にして、ランキングの盛り上がりを出す
- マップのピンも吹き出しの形にし、選んだピンはオレンジで大きく跳ねる

## 配色

| 色 | HEX | 使い方 |
| --- | --- | --- |
| インク | `#1C1A17` | 線・文字・影 |
| オレンジ | `#FF7A1A` | カテゴリのバッジ・主なボタン・選んだピン（上に載せる文字は黒） |
| イエロー | `#FFD23F` | 属性のバッジ・見出しの札・選んだタブ |

コントラスト比（`python3 Tools/check_design_contrast.py docs/design/mocks/a1`）:

| 組 | 比 |
| --- | --- |
| 本文 / カード | 17.36:1 |
| 本文 / 背景 | 15.64:1 |
| 補足の文字 / カード・背景 | 8.30:1 / 7.48:1 |
| 黒文字 / オレンジ（カテゴリのバッジ・ボタン） | 6.66:1 |
| 黒文字 / イエロー（属性のバッジ・見出しの札） | 12.02:1 |
| イエロー / インク（順位の数字・コメントの札） | 12.02:1 |

白い文字はオレンジに載せません（2.61:1 で AA 未満）。オレンジは白地のアイコンにも使わず（2.61:1 で、アイコンに求める 3:1 に届かない）、保存済みのスターは黒で塗ります。

## 書体

| 用途 | 書体 | ライセンス | 採用したときに同梱するおよそのサイズ |
| --- | --- | --- | --- |
| 見出し・ロゴ・数字 | Mochiy Pop One（1 ウェイト） | SIL OFL 1.1 | 数 MB（日本語の全字形の TTF 1 本） |
| タイトル・本文 | M PLUS Rounded 1c（Medium 500・ExtraBold 800） | SIL OFL 1.1 | 1 ウェイトあたり数 MB（2 ウェイトで 2 本） |

- サイズはおよその目安です（日本語の書体は字形が多く、1 本あたり数 MB になる）。採用するときに、使う文字だけにサブセット化して軽くすることを検討します
- 日本語と英語の見本はブランドシートに載せています

## アイコン・ロゴ・イラスト

- アプリアイコン（`icon.svg`、1024x1024）: イエローの放射線の上に、黒い縁取りのオレンジのピン。ピンの中は「！」で、本音を言い切る感じを出す。角丸は描かない
- ロゴ: 「ぶっちゃけ」を Mochiy Pop One のオレンジに黒の縁取りとずらした影、「map」をイエローの札にして少し傾けたロゴタイプ（HTML と CSS で描いている。採用したら SVG に起こす）
- 空の状態のイラスト: `empty-posts.svg`（白紙の地図の上でピンが「…」と待っている）・`empty-search.svg`（虫めがねが首をかしげている）

## 動き

| 動き | 時間 | イージング | ハプティクス | Reduce Motion のとき |
| --- | --- | --- | --- | --- |
| いいね | 約 0.6 秒（spring が落ち着くまで） | spring（response 0.35・damping 0.55）で 1.35 倍まで弾む。放射の線と `+1` のステッカー | impact（light） | 拡大と放射の線をやめ、ハートの色を 0.15 秒でクロスフェード |
| 投稿の公開のお祝い | 1.2 秒 | 「公開しました！」のステッカーが spring（response 0.4・damping 0.6）で 1.6 倍から貼り付き、紙吹雪が easeOut で 0.8 秒。ホームの先頭に `NEW` 付きのカード | notification（success） | 紙吹雪と拡大をやめ、ステッカーとカードをフェードで出す |
| マップのピンが跳ねる | 0.5 秒（シート 0.35 秒） | つぶれる → 18pt 跳ねる → 着地（spring・damping 0.5）。シートは easeOut で下から | 着地で selection | 跳ねる・つぶれるをやめ、ピンの色と大きさを 0.2 秒で切り替え、シートはフェード |

点滅はしません。

## 採用したときの本実装の注意

- **Dynamic Type**: Mochiy Pop One と M PLUS Rounded 1c を `Font.custom(_:size:relativeTo:)` で登録し、文字の大きさに合わせて拡大させる。極太の書体は大きな文字で横幅が広がるので、カードの見出しは 2 行を超えたら折り返す前提で余白を取る
- **傾いたステッカー**: 回転は飾りだけにし、VoiceOver の読み上げ順と当たり判定は回転前の矩形にする。`バズり中！` などの一言は `accessibilityHidden` にするか、いいねの数と合わせて読む
- **太い線と影**: カード・ボタンの 3pt の線とずらした影は、タップの範囲（44pt 以上）を変えないようにする
- **UI テスト**: 見た目だけの変更で、アクセシビリティの識別子（`home.feed` など）と文言は変えない。ロゴを画像にする場合も、ナビゲーションのタイトルの読み上げ（「ぶっちゃけmap」）を残す
- **App Store の素材**: アイコンとスクリーンショットの差し替えが要る（`AppStore/` のクリエイティブも作り直し）。アイコンは 1024 の PNG（アルファなし）に書き出す
- **ダークモード**: 比較の段階では作っていない。インクとクリームを入れ替えるだけでは黒い線が消えるので、採用後に線の色を決め直す

## モックで省いたこと

- 投稿詳細のツールバーの「その他」（編集・削除）は自分の投稿にだけ出るので描いていない（今のアプリと同じ）
- マップはイラストで、1 つの投稿の 3 つのピンだけを描いている（今のアプリは全国の投稿のピンを出す）
- 写真のあるスポットは描いていない（写真はカテゴリのアイコンの代わりに、同じ枠に入る）
