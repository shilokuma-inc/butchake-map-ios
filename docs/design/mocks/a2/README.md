# A-2「マンガのツッコミ」

方向性 A（ポップ＆ツッコミ）の 2 案目。A-1「王道ポップ」とは配色・書体・飾りのモチーフをすべて変えています。

## コンセプト

白地に黒のスクリーントーン・集中線・コマ枠で、マンガの 1 ページのように見せます。見出しと効果音は描き文字風（Reggae One）、
ぶっちゃけコメントは手書き風（Yusei Magic）のフキダシ。差し色は赤 1 色だけにして、「ツッコミ」の瞬間を強調します。

## 「面白さ」の出し方

- ホームの頭を集中線のコマにし、ロゴを叫びのフキダシ（ギザギザ）に入れる。添え書きは「地元民と旅人の本音、全部見せます」
- 見出しの横に効果音（`ドドン`・`ザワッ`）、いいねの多いカードにも効果音（いいね 200 以上で `ザワ…`、300 以上で `ドーン!!`）を赤の描き文字で添える
- 投稿詳細のスポットはコマ割り: 黒いコマに「1位」、写真の枠は集中線と効果音（`ドン!`・`ジャーン`）。コメントは作者の顔からしゃべるフキダシ
- マップのピンはフキダシの形。選んだピンは赤くなり、集中線と「ここだ!!」が付く
- カードやボタンは角丸を使わず、コマのように少し傾ける

## 配色

| 色 | HEX | 使い方 |
| --- | --- | --- |
| 墨 | `#111111` | 線・文字・属性のバッジ・順位・選んだタブ・ボタン |
| 白 | `#FFFFFF` | 紙（背景・カード） |
| 赤 | `#C8102E` | 差し色: 効果音・コメントの札・いいね済み・ロゴの map・選んだピン |
| 補足の文字 | `#555555` | 都道府県・住所・日付 |
| 薄いトーン | `#E9E9E9` | 地図の地 |
| 濃いトーン | `#BDBDBD` | 地図の水辺 |

スクリーントーン（網点）は墨の点を並べた模様で、文字の地には使いません（タイトルは白い帯の上に載せ、作者の行の手前で網点を白に消す）。

文字の大きさ: 本文（タイトル・スポット名・コメント）は 15pt 以上です。都道府県・住所・日付・コメントの札・扉の添え書きなどの補足は、今のアプリ（caption・footnote）と同じく 13〜14pt にしています。

コントラスト比（`python3 Tools/check_design_contrast.py docs/design/mocks/a2`）:

| 組 | 比 |
| --- | --- |
| 本文 / 白 | 18.88:1 |
| 補足の文字 / 白 | 7.46:1 |
| 赤の文字 / 白 | 5.88:1 |
| 白の文字 / 墨 | 18.88:1 |
| 白の文字 / 赤（ロゴの map・選んだピン・赤いボタン） | 5.88:1 |
| 赤の効果音 / 薄いトーン（地図の「ここだ!!」） | 4.85:1 |

## 書体

| 用途 | 書体 | ライセンス | 採用したときに同梱するおよそのサイズ |
| --- | --- | --- | --- |
| 見出し・効果音・数字 | Reggae One（1 ウェイト） | SIL OFL 1.1 | 数 MB（日本語の全字形の TTF 1 本） |
| フキダシ（ぶっちゃけコメント） | Yusei Magic（1 ウェイト） | SIL OFL 1.1 | 数 MB（1 本） |
| タイトル・本文・ロゴの map | M PLUS 1p（Medium 500・Bold 700・ExtraBold 800） | SIL OFL 1.1 | 1 ウェイトあたり数 MB（3 ウェイトで 3 本） |

- サイズはおよその目安です（日本語の書体は字形が多く、1 本あたり数 MB になる）。5 本になるので、採用するなら M PLUS 1p のウェイトを 2 つに絞ることを検討します
- Reggae One には英字の小文字が無いため、ロゴの「map」と「!?」は M PLUS 1p で組んでいます
- 日本語と英語の見本はブランドシートに載せています

## アイコン・ロゴ・イラスト

- アプリアイコン（`icon.svg`、1024x1024）: 白地に集中線、真ん中にフキダシ。中に赤の「！」と黒の「？」で、ツッコミの瞬間を 1 コマで見せる。角丸は描かない
- ロゴ: 「ぶっちゃけ」を Reggae One で少し斜めに、「map」を赤い札、最後に赤の「!?」。ホームでは叫びのフキダシと集中線のコマに入れる（HTML と CSS で描いている。採用したら SVG に起こす）
- 空の状態のイラスト: `empty-posts.svg`（白紙のコマ割りの隅でキャラが「……」）・`empty-search.svg`（汗をかく虫めがねと「!?」）

## 動き

| 動き | 時間 | イージング | ハプティクス | Reduce Motion のとき |
| --- | --- | --- | --- | --- |
| いいね（ドキッ） | 0.5 秒 | spring（response 0.3・damping 0.6）で 1.25 倍。集中線は easeOut 0.25 秒で広がって消える | impact（rigid） | 集中線・効果音・拡大をやめ、ハートの塗りを 0.15 秒でクロスフェード |
| 投稿の公開（ババーン） | 1.2 秒 | 見開きのコマが easeOut 0.3 秒で斜めに入り、叫びのフキダシが spring（damping 0.55）で 1.3 倍から。最後はコマが easeIn で縮んでホームのカードになる | notification（success） | コマの移動・集中線・拡大をやめ、フキダシとカードをフェードで出す |
| 画面遷移（コマ送り） | 0.4 秒 | 押したカードが 1.04 倍に寄り、投稿詳細が右から斜めの境目で入る（easeInOut 0.3 秒） | なし | 寄り・斜めの境目をやめ、0.2 秒のクロスフェード |

点滅はしません（集中線も明滅させず、広がって消えるだけ）。

## 採用したときの本実装の注意

- **Dynamic Type**: 3 書体を `Font.custom(_:size:relativeTo:)` で登録する。Reggae One は字幅が広いので、大きな文字では見出しを 2 行に折り返す前提で組む
- **効果音・集中線**: 飾りなので `accessibilityHidden` にする。効果音は「いいねが多い」の言い換えなので、件数は今のアプリと同じく数字で読ませる
- **スクリーントーン**: 細かい網点は端末によってモアレになりやすい。本実装では点を大きめにするか、画像ではなく `Canvas` で描いて拡大率に合わせる
- **傾いたコマ**: 傾けるのは見た目だけにし、当たり判定と読み上げ順は傾ける前の矩形にする
- **UI テスト**: 見た目だけの変更で、アクセシビリティの識別子と文言は変えない。ホームの大きなタイトルを扉のコマに置き換えるので、ナビゲーションのタイトル（「ぶっちゃけmap」）は読み上げ用に残す
- **App Store の素材**: アイコンとスクリーンショットの差し替えが要る（`AppStore/` のクリエイティブも作り直し）。アイコンは 1024 の PNG（アルファなし）に書き出す

## モックで省いたこと

- ホームはナビゲーションバーの代わりに扉のコマを置いている（本実装ではナビゲーションのタイトルを読み上げ用に残す）
- 投稿詳細のツールバーの「その他」（編集・削除）は自分の投稿にだけ出るので描いていない（今のアプリと同じ）
- マップはイラストで、1 つの投稿の 3 つのピンだけを描いている
- 写真のあるスポットは描いていない（写真は集中線の枠に入る）
