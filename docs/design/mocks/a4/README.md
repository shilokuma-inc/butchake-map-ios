# A-4「ネオブルータリズム」

方向性 A（ポップ＆ツッコミ）の 4 案目。A-1〜A-3 とは配色・書体・飾りのモチーフをすべて変えています。

## コンセプト

原色のベタ塗り（青・赤・黄・緑・薄紫）に、黒い太枠と右下へずらした影。角は丸めず、見出しは角ばった極太の Dela Gothic One。
「ぶっちゃけランキング」の勢いを、どーんと大きな順位の数字と、押すと沈むブロックのボタンで出します。

## 「面白さ」の出し方

- ホームの頭に「今週いちばんのぶっちゃけ」を、赤いベタの大きな `1` と一緒に置く
- 見出しの横に札（`NEW`・`HOT`）。カルーセルのカードは上にベタ塗りの帯（カテゴリといいねの数。いいね 200 以上は赤の帯）
- 投稿詳細のスポットは、黄・緑・薄紫の大きな順位のブロック（`1`・`2`・`3`）。写真の枠は青のベタ
- ぶっちゃけコメントは赤い札の付いた箱。マップのピンは四角いブロックで、選んだピンは赤く大きくなり、上にスポット名の札
- ボタンは押すと影が消えて右下へ沈む（ブルータリズムらしい手ごたえ）

文字の大きさ: 本文（タイトル・スポット名・コメント）は 15pt 以上、都道府県・住所・日付・札などの補足は今のアプリと同じく 13〜14pt です。

## 書体

| 用途 | 書体 | ライセンス | 採用したときに同梱するおよそのサイズ |
| --- | --- | --- | --- |
| 見出し・ロゴ・数字 | Dela Gothic One（1 ウェイト） | SIL OFL 1.1 | 数 MB（日本語の全字形の TTF 1 本） |
| タイトル・本文 | Murecho（Medium 500〜Black 900） | SIL OFL 1.1 | 可変フォント 1 本で数 MB |

- サイズはおよその目安です（日本語の書体は字形が多く、1 本あたり数 MB になる）
- Murecho は可変フォントなので、太さを何段使っても 1 本で済みます
- 日本語と英語の見本はブランドシートに載せています

## アイコン・ロゴ・イラスト

- アプリアイコン（`icon.svg`、1024x1024）: 黄色の地に、黒い太枠と影のブロックを 3 つ積んだ「三大」。いちばん上の青のブロックに白い「!」。角丸は描かない
- ロゴ: 白のブロックに Dela Gothic One の「ぶっちゃけ」、横に青のブロックの「map」（HTML と CSS で描いている。採用したら SVG に起こす）
- 空の状態のイラスト: `empty-posts.svg`（表彰台の上がぜんぶ空いている）・`empty-search.svg`（虫めがねの中が「0」）

## 動き

| 動き | 時間 | イージング | ハプティクス | Reduce Motion のとき |
| --- | --- | --- | --- | --- |
| いいね（押し込み） | 0.3 秒 | 押した瞬間に影（6pt）が消えてボタンが右下へ 6pt 沈む（linear 0.06 秒）。離すと赤くなり、easeOut 0.2 秒で影ごと戻る | 沈んだときに impact（rigid） | 沈み込みをやめ、赤への色の切り替えだけ（0.15 秒） |
| 投稿の公開（札をガツン） | 0.9 秒 | 「公開」の札が上から easeIn 0.2 秒で落ち、着地で 4pt 跳ね返る。続けてホームの新着の先頭にカードが落ち、NEW の札が 1.4 倍から easeOut 0.25 秒で貼られる | 着地で impact（heavy）、NEW の札が貼られたら notification（success） | 落下・跳ね返り・拡大をやめ、札とカードを 0.2 秒でフェードイン |
| カードの出現（ブロックが落ちる） | 0.4 秒（1 まいずつ 0.06 秒ずらす） | 24pt 上から easeIn 0.18 秒で落ち、着地で影が 0 → 5pt に伸びる（easeOut 0.12 秒） | なし（スクロールのたびに震えないよう） | 落下をやめ、影ごと 0.2 秒でフェードイン |

点滅はしません。

## 採用したときの本実装の注意

- **Dynamic Type**: 2 書体を `Font.custom(_:size:relativeTo:)` で登録する。大きな順位のブロックは文字に合わせて大きくし、カードの中で折り返す
- **太枠と影**: 3pt の枠と 5pt の影は、タップの範囲（44pt 以上）とは別に考える。押し込みの動きは `ButtonStyle` で実装する
- **原色**: ダークモードでは地を濃いグレーにし、枠と影の色を決め直す（黒い影が見えなくなるため）
- **UI テスト**: 見た目だけの変更で、アクセシビリティの識別子と文言は変えない。大きな数字は「1位」のように読ませる
- **App Store の素材**: アイコンとスクリーンショットの差し替えが要る（`AppStore/` のクリエイティブも作り直し）。アイコンは 1024 の PNG（アルファなし）に書き出す

## モックで省いたこと

- ホームの「今週いちばんのぶっちゃけ」は、いいねの数で並べた 1 件目（今のアプリの「急上昇」の先頭と同じデータ）
- カルーセルのカードには、今のカードにあるサムネイル（カテゴリのアイコン）を描いていない（カテゴリは帯に文字で出す）
- 投稿詳細のツールバーの「その他」（編集・削除）は自分の投稿にだけ出るので描いていない（今のアプリと同じ）。投稿詳細は 3 つのスポットのうち 2 つ目の途中まで
- マップはイラストで、1 つの投稿の 3 つのピンだけを描いている
- 写真のあるスポットは描いていない（写真は青の枠に入る）
