# A-5「バラエティ番組のテロップ」

方向性 A（ポップ＆ツッコミ）の 5 案目。A-1〜A-4 とは配色・書体・飾りのモチーフをすべて変えています。

## コンセプト

バラエティ番組を見ているような案です。赤・黄・白の縁取り文字、黒や赤のテロップの帯、角の丸いワイプ（リアクションの顔）、「ぶっちゃけ」のハンコ。
見出しとテロップは RocknRoll One、本文は Zen Kaku Gothic Antique で、番組のにぎやかさと「ぶっちゃけ」のツッコミ感を出します。

## 「面白さ」の出し方

- ロゴは番組のタイトルロゴ（黄色の文字に黒と赤の縁取り、斜めにして「map」を赤い札に）
- ホームの頭に「ON AIR」と、縁取りの大きな「今夜も本音、ぶっちゃけます！」とワイプの顔
- 見出しはテロップの帯（黒・赤・黄）。いいねが 200 以上のカードには「ぶっちゃけ」のハンコを押す（投稿詳細の見出しと、公開したばかりの自分の投稿には、いいねの数に関係なく押す）
- 投稿詳細のスポットは番組の画面の枠: 左上に「第1位」のテロップ、右下にワイプの顔（驚き・にっこり・ツッコミ）。コメントは下テロップ
- マップの選んだピンは黄色になり、上にスポット名のテロップ

## 書体

| 用途 | 書体 | ライセンス | 採用したときに同梱するおよそのサイズ |
| --- | --- | --- | --- |
| 見出し・テロップ・ロゴ・タイトル・数字 | RocknRoll One（1 ウェイト） | SIL OFL 1.1 | 数 MB（日本語の全字形の TTF 1 本） |
| 本文 | Zen Kaku Gothic Antique（Medium 500・Bold 700） | SIL OFL 1.1 | 1 ウェイトあたり数 MB（2 本） |

- サイズはおよその目安です（日本語の書体は字形が多く、1 本あたり数 MB になる）
- 日本語と英語の見本はブランドシートに載せています

## アイコン・ロゴ・イラスト

- アプリアイコン（`icon.svg`、1024x1024）: 青い番組の画面に、黒の縁取りの黄色い吹き出しのピン（驚きの顔）と、赤いハンコ。下に黒のテロップの帯。角丸は描かない
- ロゴ: 番組のタイトルロゴ風のロゴタイプ（HTML と CSS で描いている。採用したら SVG に起こす）
- 空の状態のイラスト: `empty-posts.svg`（放送前のカラーバーと「準備中」のテロップ）・`empty-search.svg`（ワイプの顔が「？」とツッコむ）

## 動き

| 動き | 時間 | イージング | ハプティクス | Reduce Motion のとき |
| --- | --- | --- | --- | --- |
| いいね（ワイプのリアクション） | 0.6 秒 | ハートは spring（response 0.3・damping 0.6）で 1.2 倍。右下にワイプの顔が easeOut 0.2 秒で出て、0.25 秒後にフェードで消える | 塗ったときに impact（medium） | ワイプと拡大をやめ、ハートの塗りと件数の色を 0.15 秒でクロスフェード |
| 投稿の公開（テロップがドーン） | 1.2 秒 | 画面が少し暗くなり、縁取りの大きな「公開！」が 1.6 倍から spring（damping 0.55）で出る。続けて下テロップが右から easeOut 0.25 秒で入る | 大きなテロップが出たときに notification（success） | 拡大と横の移動をやめ、テロップを 0.2 秒でフェードイン |
| カードの出現（テロップ風） | 0.4 秒（1 まいずつ 0.06 秒ずらす） | 左から 40pt、easeOut 0.3 秒で滑り込み、最後に 1.02 倍から 1 倍に戻る | なし（スクロールのたびに震えないよう） | 横の移動をやめ、0.2 秒でフェードイン |

点滅はしません（テロップも明滅させない）。

## 採用したときの本実装の注意

- **Dynamic Type**: 2 書体を `Font.custom(_:size:relativeTo:)` で登録する。縁取り文字は `stroke` を文字の大きさに合わせて太くする（SwiftUI では重ねた `Text` か `Canvas` で描く）
- **縁取り文字の読み上げ**: 「今夜も本音、ぶっちゃけます！」などの飾りの文字は `accessibilityHidden` にし、見出し（「今週のぶっちゃけ」など）だけを読ませる。ハンコとワイプの顔も飾り
- **テロップの帯の斜めの切り落とし**: 文字が大きいと右端で切れるので、帯の右の余白を文字の大きさに合わせる
- **UI テスト**: 見た目だけの変更で、アクセシビリティの識別子と文言は変えない。ホームの大きなタイトルをロゴにするので、ナビゲーションのタイトル（「ぶっちゃけmap」）は読み上げ用に残す
- **App Store の素材**: アイコンとスクリーンショットの差し替えが要る（`AppStore/` のクリエイティブも作り直し）。アイコンは 1024 の PNG（アルファなし）に書き出す

## モックで省いたこと

- ホームの「ON AIR」の帯は案の雰囲気を見せる飾り（今のアプリに無い見出し）
- 投稿詳細のツールバーの「その他」（編集・削除）は自分の投稿にだけ出るので描いていない（今のアプリと同じ）。投稿詳細は 3 つのスポットのうち 2 つ目の途中まで
- シェアカードはブランドシートにだけ描いている（投稿詳細ではツールバーの共有ボタンから出る）
- マップはイラストで、1 つの投稿の 3 つのピンだけを描いている
- 写真のあるスポットは描いていない（写真は番組の画面の枠に入る）
