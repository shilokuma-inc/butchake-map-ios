# B-1「昭和の観光パンフ」

方向性 B（レトロ観光パンフ）の 1 案目。Discussion #45 の B の説明をそのまま形にした案です。

## コンセプト

クリーム地に朱色と紺。昔の観光案内のパンフレットをめくるように、切手のミシン目のカード・消印・二重線の飾りを使い、
見出しは太いレトロなゴシック（Dela Gothic One）、添え書きと順位は明朝（しっぽり明朝 B1）にします。懐かしさと、旅先をめくるわくわく感を出します。

## 「面白さ」の出し方

- ホームの「今週のぶっちゃけ」「急上昇」を切手のカードにし、額面の代わりに「三大」と縦書きで入れる。見出しには「今週の名所案内」「いま人気の旅先」「旅だより」と明朝の添え書き
- フィードのカードと投稿詳細に、投稿日の消印（`2026 / 10.18 / 金沢市`）を押す
- 順位を漢数字（一・二・三）の朱の角印にし、投稿詳細では「其の一」「其の二」の帯でスポットを紹介する
- 投稿詳細の写真の枠を、紺の地に波と太陽の絵はがき風にする（写真が無いとき）。ぶっちゃけコメントは罫線の入った便せん
- マップは観光案内図のように、線路・方位・地名の札を添える。ピンは朱の丸いはんこ

## 書体

| 用途 | 書体 | ライセンス | 採用したときに同梱するおよそのサイズ |
| --- | --- | --- | --- |
| 見出し・ロゴ・数字 | Dela Gothic One（1 ウェイト） | SIL OFL 1.1 | 数 MB（日本語の全字形の TTF 1 本） |
| 添え書き・順位・消印 | しっぽり明朝 B1（ExtraBold 800） | SIL OFL 1.1 | 数 MB（1 ウェイト） |
| タイトル・本文 | Zen Kaku Gothic New（Medium 500・Bold 700） | SIL OFL 1.1 | 1 ウェイトあたり数 MB（2 ウェイトで 2 本） |

- サイズはおよその目安です（日本語の書体は字形が多く、1 本あたり数 MB になる）。3 書体 4 本になるので、採用するなら明朝は使う文字（漢数字・添え書き）だけにサブセット化することを検討します
- 日本語と英語の見本はブランドシートに載せています

## アイコン・ロゴ・イラスト

- アプリアイコン（`icon.svg`、1024x1024）: ミシン目の切手の中に、紺の地の山・朱の太陽・波。左上に朱の消印。角丸は描かない
- ロゴ: 「ぶっちゃけ」を Dela Gothic One の紺、「map」を朱の丸い印にしたロゴタイプ。下に明朝の「全国本音観光案内」を添える（狭い場所では添え書きを外す。HTML と CSS で描いている。採用したら SVG に起こす）
- 空の状態のイラスト: `empty-posts.svg`（切手帳の空いた枠が 3 つ）・`empty-search.svg`（行き先の札が白紙の道しるべと、朱の「？」）

## 動き

| 動き | 時間 | イージング | ハプティクス | Reduce Motion のとき |
| --- | --- | --- | --- | --- |
| いいね（はんこを押す） | 0.5 秒 | はんこが easeIn 0.1 秒で下り、押した瞬間にボタンが 0.96 倍へ縮んで戻る（spring・damping 0.7）。朱の「いいね」の印は 0.3 秒残してフェード | impact（medium） | はんこと印を出さず、ハートの塗りと件数を 0.15 秒でクロスフェード |
| 投稿の公開（消印を押す） | 1.0 秒 | 切手のカードが easeOut 0.25 秒で上がり、消印が 1.4 倍から spring（damping 0.6）で押される。カードが 2pt だけ 2 往復揺れ、easeInOut でホームの「旅だより」の先頭へ | notification（success） | 上がる・揺れる・飛ぶをやめ、消印とホームのカードをフェードで出す |
| カードの出現（切手を貼る） | 0.55 秒（1 枚 0.3 秒・0.08 秒ずつずらす） | 1 枚ずつ 8pt 上から ±4° 傾けて置き、easeOut で戻す | なし（スクロールのたびに震えないよう） | 傾き・移動をやめ、まとめて 0.2 秒でフェードイン |

点滅はしません（揺れは 2 往復だけ）。

## 採用したときの本実装の注意

- **Dynamic Type**: 3 書体を `Font.custom(_:size:relativeTo:)` で登録する。切手のカードは高さを固定せず、文字が大きいときはミシン目の枠ごと伸ばす（モックのカルーセルは高さを固定している）
- **ミシン目**: SwiftUI では `Shape` で縁に半円の切り欠きを並べて描く（マスクの画像は使わない）。ダークモードでは紙とクリームの色を決め直す
- **漢数字の順位**: VoiceOver では「1位」のように読ませる（`accessibilityLabel`）。「其の一」の帯も同じ
- **消印・はんこ**: 飾りなので `accessibilityHidden` にし、投稿日は今のアプリと同じく文字で読ませる
- **UI テスト**: 見た目だけの変更で、アクセシビリティの識別子と文言は変えない
- **App Store の素材**: アイコンとスクリーンショットの差し替えが要る（`AppStore/` のクリエイティブも作り直し）。アイコンは 1024 の PNG（アルファなし）に書き出す
- **画像の権利**: 山と太陽と波は自分で描いた図形。特定の山や名所の写真・絵は使っていない

## モックで省いたこと

- 投稿詳細のツールバーの「その他」（編集・削除）は自分の投稿にだけ出るので描いていない（今のアプリと同じ）
- マップはイラストで、1 つの投稿の 3 つのピンだけを描いている。地名の札（近江町・香林坊）は案内図の雰囲気を見せる飾り
- 写真のあるスポットは描いていない（写真は絵はがきの枠に入る）
