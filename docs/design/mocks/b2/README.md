# B-2「駅のスタンプラリー」

方向性 B（レトロ観光パンフ）の 2 案目。B-1「昭和の観光パンフ」とは配色・書体・飾りのモチーフをすべて変えています。

## コンセプト

駅のスタンプラリーの台紙を、そのままアプリにした案です。紺一色のインクのスタンプ、クラフト紙の台紙、駅名標・きっぷ・路線図。
投稿の 3 つのスポットを路線の 3 つの駅に見立て、行った場所にスタンプを集める楽しさと、旅の道のりのわくわく感を出します。

## 「面白さ」の出し方

- ホームの頭に「スタンプ帳」（今月あつめたスタンプの数）を置く。見出しは駅名標で、帯に前後の見出し（◀ 今週のぶっちゃけ ／ 新着の投稿 ▶）を出す
- カルーセルのカードは「ぶっちゃけ線」のきっぷ（日付・「〇〇 ゆき」・改札のはさみの切り込み）
- フィードのカードはスタンプラリーの台紙: 3 つのスポットと、投稿日のスタンプ
- 投稿詳細は、都市の駅名標（`金沢市 / KANAZAWA`、帯にカテゴリと投稿者の属性）の下に、3 つのスポットを路線図の駅として縦に並べる。行った駅にはスタンプ「済」、まだの駅は点線の空き欄「未」
- マップでは 3 つのピンを順位の順（1 → 2 → 3）に路線でつなぎ、選んだ駅に小さな駅名標（前後の駅の番号つき）を立てる
- ぶっちゃけコメントは駅の掲示板

## ダークモードの配色（夜の駅）

Discussion #77 の Q3 で、ダークの配色はモックで確かめてから実装すると決めました。地を夜の紺に暗くし（PR #79 の確認で、黒すぎないよう少し明るめにした）、紺のインクと路線の緑を明るくして文字と線に使います。
インク・緑・文字色の地に載せる文字（ライトでは白）は、ダークでは地の色にします。

- スタイルは `theme-dark.css`（`theme.css` とページのスタイルの後に読み込む）、色の組は `palette-dark.json`
- 画面は `home-dark.html`・`detail-dark.html`・`map-dark.html`（ライトのページと同じ `<ページ>.css`・`<ページ>.js` を読み、`theme-dark.css` を足しただけ）。ブランドシートは `brand-dark.html`
- 空の状態のイラスト（`empty-posts.svg`・`empty-search.svg`）とアプリアイコンは、ライトと同じ色のままダークの地に置いています

## 書体

| 用途 | 書体 | ライセンス | 採用したときに同梱するおよそのサイズ |
| --- | --- | --- | --- |
| 駅名標・見出し・本文 | BIZ UDPゴシック（Regular 400・Bold 700） | SIL OFL 1.1 | 1 ウェイトあたり数 MB（2 ウェイトで 2 本） |
| きっぷ・英字・数字（発車標） | DotGothic16（1 ウェイト） | SIL OFL 1.1 | 数 MB（1 本） |
| スタンプの文字 | Kaisei Decol（Bold 700） | SIL OFL 1.1 | 数 MB（1 本） |

- サイズはおよその目安です（日本語の書体は字形が多く、1 本あたり数 MB になる）。Kaisei Decol はスタンプの数文字だけなので、採用するなら使う文字だけにサブセット化することを検討します
- BIZ UDPゴシックはユニバーサルデザインの書体で、駅の案内のような読みやすさを出せます
- 日本語と英語の見本はブランドシートに載せています

## アイコン・ロゴ・イラスト

- アプリアイコン（`icon.svg`、1024x1024）: クラフト紙の台紙に、紺一色の駅スタンプ（点線と二重の丸・電車・山・線路）。下に路線の緑の帯。インクのかすれも描く。角丸は描かない
- ロゴ: 駅名標の形のロゴタイプ。「ぶっちゃけ」は BIZ UDPゴシック、「map」をインクの紺、下に `BUTCHAKE MAP`、緑の帯に「◀ ほんね ／ たび ▶」（HTML と CSS で描いている。採用したら SVG に起こす）
- 空の状態のイラスト: `empty-posts.svg`（スタンプ帳の台紙。最初の 1 こを押す欄が空いている）・`empty-search.svg`（駅名が「？」で、前後の駅も空白の駅名標）

## 動き

| 動き | 時間 | イージング | ハプティクス | Reduce Motion のとき |
| --- | --- | --- | --- | --- |
| いいね（発車標がパタパタ） | 0.4 秒 | ハートは easeOut 0.15 秒で塗る。件数は変わる桁だけ、発車標の札が上から下へ easeIn 0.12 秒ずつ 2 段で回る | 札が止まったときに selection | 札を回さず、ハートの塗りと件数を 0.15 秒でクロスフェード |
| 投稿の公開（スタンプを押す） | 1.0 秒 | スタンプ台が easeIn 0.2 秒で下りて押し、0.08 秒止まって easeOut で上がる。インクの丸は 1.1 倍からにじんで 1.0 倍に | 押した瞬間（0.20 秒）に impact（heavy）、3 こそろったら notification（success） | スタンプ台を出さず、インクの丸と「公開しました」を 0.2 秒でフェードイン |
| 画面遷移（次の駅へ） | 0.45 秒 | 押してから 0.1 秒後に動き始め、上の路線の帯の紺の丸と、右から入る投稿詳細が、easeInOut 0.35 秒で同じ割合だけ進む | 駅に着いたとき（0.45 秒）に selection | 帯の移動と横の移動をやめ、0.2 秒のクロスフェード |

点滅はしません。

## 採用したときの本実装の注意

- **Dynamic Type**: 3 書体を `Font.custom(_:size:relativeTo:)` で登録する。駅名標は文字が大きいと横にあふれるので、2 行に折り返すか、帯の前後の見出しを省く
- **スタンプ帳**: 「今月あつめたスタンプ」は今のアプリに無い機能の見せ方です。採用するなら、自分の投稿の数から数えるなど、今あるデータで出せる形に決め直す（モックの「2 / 3 こ」は飾り）
- **路線図の駅のスタンプ「済」「未」**: 今のアプリに「行った」の記録は無いので、採用するなら飾りにとどめるか、別の機能として検討する。VoiceOver ではスタンプを読み上げない
- **発車標の数字**: 回転は見た目だけにし、件数は今のアプリと同じく数字で読ませる
- **UI テスト**: 見た目だけの変更で、アクセシビリティの識別子と文言は変えない。ホームの大きなタイトルを駅名標のロゴにするので、ナビゲーションのタイトル（「ぶっちゃけmap」）は読み上げ用に残す
- **App Store の素材**: アイコンとスクリーンショットの差し替えが要る（`AppStore/` のクリエイティブも作り直し）。アイコンは 1024 の PNG（アルファなし）に書き出す

## モックで省いたこと

- 投稿詳細のツールバーの「その他」（編集・削除）は自分の投稿にだけ出るので描いていない（今のアプリと同じ）
- 投稿詳細は 3 つのスポットのうち 2 つ目の途中まで（スクロールした先に 3 つ目）
- マップはイラストで、1 つの投稿の 3 つのピンだけを描いている。3 の駅はモックデータの位置（1 と 2 の間）だと路線が重なるので、このモックだけ右上に置いている
- 写真のあるスポットは描いていない（写真は駅のカードの上に入る）
- カルーセルのきっぷには、今のカードにあるサムネイル（カテゴリのアイコン）を描いていない（カテゴリはバッジで出している）。きっぷの地は白に薄い緑の斜線で、文字の比は白地の値で見ている（斜線の分だけわずかに下がるが、どの組も 4.5:1 を十分に超える）
