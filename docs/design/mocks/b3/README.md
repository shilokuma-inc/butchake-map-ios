# B-3「純喫茶のメニュー」

方向性 B（レトロ観光パンフ）の 3 案目。B-1「昭和の観光パンフ」・B-2「駅のスタンプラリー」とは配色・書体・飾りのモチーフをすべて変えています。

## コンセプト

昭和の純喫茶でメニューをめくる時間を、そのまま画面にした案です。クリーム・こげ茶・赤に、クリームソーダの緑をひとさじ。
レースペーパー、メニュー表の点線のリーダー、金の細い罫で飾り、見出しは明朝（Zen Old Mincho）、英字の添え書きは筆記体（Playfair Display Italic）にします。

## 「面白さ」の出し方

- ロゴは喫茶店の看板: 筆記体の `Kissa Butchake`・明朝の「ぶっちゃけmap」・金の罫に `since 2026`
- ホームの頭はレースペーパーの「本日のおすすめ」。見出しの横に筆記体の英字（`This week`・`Popular`・`New`）と金の二重罫
- カルーセルのカードはメニュー表: 3 つのスポットを品書きのように並べ、点線のリーダーの先に `No.1`・`No.2`・`No.3`
- 投稿詳細は、レースペーパーの表紙（`Today's special`）と、スポットごとのメニューのカード（お皿の上のカテゴリのアイコン・大きな `No.1`）
- ぶっちゃけコメントは罫線の入った伝票、マップの選んだピンには湯気

## 書体

| 用途 | 書体 | ライセンス | 採用したときに同梱するおよそのサイズ |
| --- | --- | --- | --- |
| 見出し・ロゴ・タイトル | Zen Old Mincho（Bold 700・Black 900） | SIL OFL 1.1 | 1 ウェイトあたり数 MB（2 本） |
| 本文 | Kiwi Maru（Regular 400・Medium 500） | SIL OFL 1.1 | 1 ウェイトあたり数 MB（2 本） |
| 英字の添え書き・数字 | Playfair Display（Italic 500・700） | SIL OFL 1.1 | 数百 KB（英字だけ） |

- サイズはおよその目安です（日本語の書体は字形が多く、1 本あたり数 MB になる）
- Playfair Display は英字だけの書体なので、日本語には使いません（英字の添え書きと `No.1` などの数字だけ）
- 日本語と英語の見本はブランドシートに載せています

## アイコン・ロゴ・イラスト

- アプリアイコン（`icon.svg`、1024x1024）: こげ茶の地にレースペーパー（縁の波形と穴）、その上に赤いコーヒーカップと金の縁のソーサー、金の湯気。角丸は描かない
- ロゴ: 喫茶店の看板の形のロゴタイプ（筆記体の `Kissa Butchake`・明朝の「ぶっちゃけmap」・金の罫の `since 2026`）。狭い場所では `since` の罫を外す（HTML と CSS で描いている。採用したら SVG に起こす）
- 空の状態のイラスト: `empty-posts.svg`（品書きがまだ白紙のメニュー表と、赤い「準備中」の札（札の文字は線で略している））・`empty-search.svg`（飲み終わってからっぽのカップ）

## 動き

| 動き | 時間 | イージング | ハプティクス | Reduce Motion のとき |
| --- | --- | --- | --- | --- |
| いいね（湯気のハート） | 0.7 秒 | ハートは easeOut 0.2 秒で塗る。小さなハートが 2 つ、湯気のように easeOut 0.6 秒でゆらぎながら 24pt 上がって消える | 塗ったときに impact（soft） | 立ちのぼるハートを出さず、塗りと件数の色を 0.15 秒でクロスフェード |
| 投稿の公開（承りました） | 1.1 秒 | 伝票が easeOut 0.3 秒で下から上がり、赤い丸印が 1.3 倍から spring（damping 0.7）で押される。伝票は easeInOut でホームの「新着の投稿」の先頭へ | 印を押した瞬間に notification（success） | 上がる・押し込む・移動をやめ、印と「公開しました」を 0.2 秒でフェードイン |
| 画面遷移（メニューをめくる） | 0.5 秒 | 今のページが左の綴じ目を軸に easeInOut 0.45 秒で 0° → -100° に回り、下から投稿詳細のページが出る | なし | めくりをやめ、0.2 秒のクロスフェード |

点滅はしません。

## 採用したときの本実装の注意

- **Dynamic Type**: 3 書体を `Font.custom(_:size:relativeTo:)` で登録する。メニュー表の 1 行（名前……`No.1`）は、文字が大きいと名前が省略されるので、大きいときはリーダーをやめて 2 行に折り返す
- **筆記体の英字**: `This week` などは見出しの飾りなので `accessibilityHidden` にし、日本語の見出しだけを読ませる。`No.1` は「1位」と読ませる
- **レースペーパー**: モックは点線の縁で表している。本実装では `Shape` で波形の縁を描く。ダークモードでは紙とクリームの色を決め直す
- **めくりの遷移**: カスタムの遷移は `NavigationStack` の標準の戻るジェスチャーと両立させる（めくりは進むときだけにする案も検討）
- **UI テスト**: 見た目だけの変更で、アクセシビリティの識別子と文言は変えない。ホームの大きなタイトルを看板のロゴにするので、ナビゲーションのタイトル（「ぶっちゃけmap」）は読み上げ用に残す
- **App Store の素材**: アイコンとスクリーンショットの差し替えが要る（`AppStore/` のクリエイティブも作り直し）。アイコンは 1024 の PNG（アルファなし）に書き出す

## モックで省いたこと

- ホームの「本日のおすすめ」は案の雰囲気を見せる飾り（今のアプリに無い見出し。採用するなら今ある見出しに置き換える）
- カルーセルのカード（メニュー表）には、今のカードにあるサムネイル（カテゴリのアイコン）を描いていない（カテゴリは上の小さな文字で出している）
- 投稿詳細のツールバーの「その他」（編集・削除）は自分の投稿にだけ出るので描いていない（今のアプリと同じ）
- マップはイラストで、1 つの投稿の 3 つのピンだけを描いている
- 写真のあるスポットは描いていない（写真はお皿の位置に丸く入る）
- 投稿詳細は 3 つのスポットのうち 2 つ目の途中まで（スクロールした先に 3 つ目）
- シェアカードはブランドシートにだけ描いている（投稿詳細ではツールバーの共有ボタンから出る。今のアプリと同じ）
- 順位は、フィードとカルーセルのカードでは行末の `No.1` だけで示す（丸い順位は投稿詳細とマップで使う）
