# B-5「昭和の銭湯と看板」

方向性 B（レトロ観光パンフ）の 5 案目。B-1〜B-4 とは配色・書体・飾りのモチーフをすべて変えています。

## コンセプト

昭和の銭湯で、ひとっ風呂あびて本音をこぼす気楽さの案です。水色と朱、白いタイルの目地、富士山のペンキ絵、のれん、下足札の木札、ホーロー看板。
見出しは筆文字（Yuji Syuku）、ロゴは立体の看板文字（Rampart One）で、懐かしくて肩の力が抜けた雰囲気を出します。

## 「面白さ」の出し方

- ロゴは朱の「ゆ」の札と、立体の看板文字の「ぶっちゃけmap」
- ホームの頭は「ぶ・っ・ち・ゃ・け」ののれんと、その奥の富士山のペンキ絵（「本音で、ひとっ風呂。」）
- 見出しは木札、カルーセルのカードには都道府県の下足札を縦に掛ける
- 投稿詳細は紺のホーロー看板の見出し（白い縁と角のねじ）、スポットは「壱番」「弐番」の下足札と、ペンキ絵の写真の枠。コメントは脱衣所の貼り紙
- マップのピンは「ゆ」ののれんの形で、選んだピンは朱になり湯気が立つ

## 書体

| 用途 | 書体 | ライセンス | 採用したときに同梱するおよそのサイズ |
| --- | --- | --- | --- |
| 見出し・木札・のれん | Yuji Syuku（1 ウェイト） | SIL OFL 1.1 | 数 MB（日本語の全字形の TTF 1 本） |
| ロゴ・看板 | Rampart One（1 ウェイト） | SIL OFL 1.1 | 数 MB（1 本。ロゴだけなので使う文字にサブセット化できる） |
| タイトル・本文 | Zen Kaku Gothic New（Medium 500・Bold 700） | SIL OFL 1.1 | 1 ウェイトあたり数 MB（2 本） |

- サイズはおよその目安です（日本語の書体は字形が多く、1 本あたり数 MB になる）
- Rampart One はロゴにしか使わないので、採用するならロゴを SVG にして書体を同梱しない手もある
- 日本語と英語の見本はブランドシートに載せています

## アイコン・ロゴ・イラスト

- アプリアイコン（`icon.svg`、1024x1024）: 白いタイルの壁に富士山のペンキ絵、手前に湯気のしるしの朱ののれん、下に紺のホーロー看板。角丸は描かない
- ロゴ: 朱の「ゆ」の札と、Rampart One の「ぶっちゃけmap」（HTML と CSS で描いている。採用したら SVG に起こす）
- 空の状態のイラスト: `empty-posts.svg`（下足箱の木札がぜんぶ空いている）・`empty-search.svg`（湯けむりで奥が見えない湯船と「？」）

## 動き

| 動き | 時間 | イージング | ハプティクス | Reduce Motion のとき |
| --- | --- | --- | --- | --- |
| いいね（湯の泡） | 0.7 秒 | ハートは easeOut 0.15 秒で塗る。小さな泡が 3 つ、easeOut 0.55 秒でゆらぎながら 30pt 上がって消える | 塗ったときに impact（soft） | 泡を出さず、ハートの塗りと件数の色を 0.15 秒でクロスフェード |
| 投稿の公開（下足札を掛ける） | 0.9 秒 | 「壱番」の木札が上から easeIn 0.2 秒で下りてカチッと掛かり、2 回だけ小さく揺れる（spring・damping 0.5）。続けて「公開しました」の貼り紙がフェードで出る | 掛かった瞬間に impact（rigid）、貼り紙で notification（success） | 下りる・揺れるをやめ、木札と貼り紙を 0.2 秒でフェードイン |
| 画面遷移（のれんをくぐる） | 0.5 秒 | のれんが上から easeOut 0.15 秒で下り、真ん中から左右へ easeInOut 0.3 秒で分かれて、奥の投稿詳細が見える | なし | のれんを出さず、0.2 秒のクロスフェード |

点滅はしません。

## 採用したときの本実装の注意

- **Dynamic Type**: 3 書体を `Font.custom(_:size:relativeTo:)` で登録する。縦書きの下足札は文字が大きいと縦に伸びるので、大きいときは横書きの札に切り替える
- **漢数字の順位**: 「壱番」「弐番」は VoiceOver で「1位」のように読ませる。のれんの 1 文字ずつの文字や湯気は飾りなので `accessibilityHidden`
- **のれんの遷移**: カスタムの遷移は `NavigationStack` の標準の戻るジェスチャーと両立させる（のれんは進むときだけにする案も検討）
- **タイルの目地**: 細い格子は端末によってモアレになりやすいので、本実装では目地を太めにするか、無地にする
- **UI テスト**: 見た目だけの変更で、アクセシビリティの識別子と文言は変えない。ホームの大きなタイトルを看板のロゴにするので、ナビゲーションのタイトル（「ぶっちゃけmap」）は読み上げ用に残す
- **App Store の素材**: アイコンとスクリーンショットの差し替えが要る（`AppStore/` のクリエイティブも作り直し）。アイコンは 1024 の PNG（アルファなし）に書き出す
- **画像の権利**: 富士山のペンキ絵は自分で描いた図形。実在の銭湯の絵や看板は使っていない

## モックで省いたこと

- ホームののれんとペンキ絵の帯は案の雰囲気を見せる飾り（今のアプリに無い見出し）
- カルーセルのカードには、今のカードにあるサムネイル（カテゴリのアイコン）を描いていない（都道府県の下足札とカテゴリのバッジで出す）
- 投稿詳細のツールバーの「その他」（編集・削除）は自分の投稿にだけ出るので描いていない（今のアプリと同じ）。投稿詳細は 3 つのスポットのうち 2 つ目の途中まで
- シェアカードはブランドシートにだけ描いている（投稿詳細ではツールバーの共有ボタンから出る）
- マップはイラストで、1 つの投稿の 3 つのピンだけを描いている
- 写真のあるスポットは描いていない（写真はペンキ絵の枠に入る）
